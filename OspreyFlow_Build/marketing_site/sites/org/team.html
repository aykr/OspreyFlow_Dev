How it is built

The design, the architecture and every decision in OspreyFlow are the team's. Much of the code is written with AI coding tools working to that design, and every change passes the same reviews, tests and checks before it is merged. We say so because provenance matters in this product, and it matters in how the product is made.

RoleWhat it meansHow someone gets there
