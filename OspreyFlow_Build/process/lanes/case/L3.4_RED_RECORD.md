# L3.4 red record: each check shown red by a plant at its real call site (rules 12 and 15)

Each plant is kept as a test of its own beside the check it proves: it puts in the defect, in the
shape the real call site would produce, and asserts the defect's effect is visible. If the main check
could not see it, the plant's own assertion would fail. Plants that need no test (a handler removed)
were run once by hand, and the result is recorded here. All plants are restored.

## Found by the checks while building (fixed, not plants)

- The Studio's dataset routes were first written above `StudioDatasetDep`'s definition. FastAPI could
  not resolve the annotation there and silently dropped the dataset's gate: `dataset_id` became a bare
  path parameter. This was caught by reading each route's resolved dependencies before any test ran.
  The routes now sit below the gate, and each route's dependency list includes `require_studio_dataset`.
- A path parameter named `investigation_id` on a dataset route made `get_principal` scope the request
  to that case, so the dataset's gate refused its own Authors. It is now `case_id`.
- The reviewer's read of the layer alone hid a drawn link to a loaded node, whose end is in the
  dataset. The read now covers the layer and the dataset.
- GOV.UK's hint grey failed colour contrast on the panel's surface (axe, GOV.UK variant). The reason
  is now in the token's secondary text colour.
- Focusing a sheet one animation frame later raced React's commit: the keyboard cases failed one run in
  three. Focus now moves in an effect after the sheet is drawn.
