# Case lane · L3.4 plan · promotion, and a removed case's layer merged or deleted

Working from: ADR-143 decisions 1, 2, 5, 8, 9, 10 and its rule list; Amendment 2 decisions 1 and 3;
Amendment 3; Amendment 4 (case-b's, on `lane/case-b`: `LinkTypeService.promotion_refusals`); ADR-145
decision 8 and Amendment 4 decisions 2, 3, 6 and 11; ADR-145 Amendment 6 (admin's L2.6 seam, on
`lane/admin`); ADR-133 Amendment 8; spec 01 §(analyst layer, drawn item), spec 03 §3.1c.

## Shape

- **The record** (`services/api/promotion_store.py`, new): one row per promotion: its `load_id`, trigger
  (`analyst_promotion` | `layer_merge`), case, board, target dataset, layer, proposer, when, status
  (`awaiting_review` | `committed` | `rejected`), reviewer, reason, the element ids it carries, what it left
  out and why, its highest marking. In memory and Postgres. The same store holds the **merge read grant**
  (one per merge, opened by the sheet, closed with the merge) and answers admin's `WaitingPromotions` seam
  (`waiting_for_review(reader)` filtered in SQL by unit and clearance; `all_waiting()`).
- **The graph** (`ports/graph.py`, the ArcadeDB adapter, the fakes, the stamping wrapper): three writes,
  conformance first:
  - `promote_elements(nodes, links, dataset, load_id, tx)`: each live element gains the dataset (ADR-099's
    union, never a copy), stamped `promoted_by_load`; any id not live refuses the whole call.
  - `revert_promotion(load_id, dataset, tx)`: the dataset taken back from exactly those elements.
  - `withdraw_layer(dataset, withdrawal, tx)`: every live element wholly that dataset's reverted; an
    element holding another dataset (promoted) untouched.
- **The service** (`services/api/promotions.py`, new): the sheet (what goes, every check, left-out items
  with reasons, undecided matches as warnings, how it is recorded); `promote` re-running every check at the
  route; commit as one graph transaction; review by the policy's approvers (the dataset's home-case Authors
  holding `review_promotions`, never the proposer); the layer merge (Authors only, removed case, never a
  composite case's layer) and delete (an Author or an administrator).
- **Routes** (app.py, the case/board/promotion routes): the sheet, promote, the board's promotions, the
  Studio's list, details, approve, reject; the layer's merge sheet, merge, delete.
- **Revert**: the core `revert_promotion` and an operator command `python -m scripts.revert_promotion`
  (Conduit stopped, ADR-127 Amendment 9). No online path until the owner rules on open question 2.
- **The Glass**: `boards/PromoteSheet.tsx` and *Promotions from this board*; `ingest/runs/promotions*` (the
  Studio's *Analyst promotions* list, review, removed cases' layers); keyboard cases and axe in three themes.

## Tests written first (each shown red by a plant at the real call site)

1. Conformance (`tests/conformance/graph_port/test_promotion.py`, live): one element after promotion,
   `datasets` holding both (red with a copy); all or nothing (red per item); revert leaves the layer only;
   `withdraw_layer` leaves a promoted element.
2. `tests/services/api/test_promotions.py` (the real app, `board_fakes.BoardGraph`):
   one load all or nothing; a link with an unpromoted drawn end left out and listed; above the dataset's
   highest marking refused at the sheet and at the route (sheet bypassed); a type outside the model / a
   proposed link type refused; the proposer cannot approve, an approver can, a non-approver Author cannot;
   nothing readable in another case before review, readable after; every route refuses a non-member as a
   missing case (another case of the same dataset included); the reviewer reads only the promotion's items
   and only what their clearance allows; the merge grant ends with the merge (red with it kept); a composite
   case's layer never merged; delete leaves promoted items; `promoted_at` set; an unseen promoted link stays.
3. `tests/services/api/test_promotion_store.py` (real Postgres): the seam's reader filter in SQL.
4. `keyboard/boards.spec.ts` (promote) and `keyboard/promotions.spec.ts` (review, merge, delete); registry
   ids as a diff; axe in dark, light and GOV.UK.
