# AD1a after round 6 (the last round the owner gave): the table, row by row (20 November 2026)

AD1a is **stopped at round 6 of 6**. Sources: the round-6 verifier (`verify-c66961a…`, five faults in behaviour) and a read-only scout of the same tip, judged against `AD1a_KEY_PATHS_TABLE.md` (rows 1 to 39). Main was taken in (SE5's merge commit is an ancestor; SE5's tests and code are on the branch). Nothing was run by the scout; the verifier's traces are by reading.

**The question this table puts to the owner (row 36):** may start-up list the gateway's credentials and keep **only the names**, discarding the values at the call (never held, never logged, never audited), so that it can mark an engine whose record says "set" and has no credential? Without that, the gap is named in the release notes. Recommended: yes, names only, with a test that no fragment reaches a log, an answer or an audit.
