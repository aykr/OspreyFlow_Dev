## The owner's rulings (21 November 2026, on the table)

1. **The definition the register applies.** *Software and base images are open source when their licence is approved by the Open Source Initiative, which includes GPL-2.0 with the Classpath exception; model weights by the same test on the weights' own licence; data by a recognised open-data licence, which covers ODbL and OGL. The stricter allowlist in section 7 stays as it is for code.* **The register has a column saying which test each row passed.**
2. **Every "not stated" row is filled from the source, never from memory or from any message:** the licence file or model card at the exact digest, revision or tag the product pins, with where it was read. The owner's adviser read the publishers' pages for W3 to W7 (qwen2.5:0.5b-instruct, all-minilm, moondream, faster-whisper-tiny.en, the Stanza models) on 21 November and found Apache-2.0 or MIT for all five. **That report is not a source: confirm each at the pinned version.** **If any row turns out not to pass the definition, stop and bring it to the owner before it is registered.**
3. **Base images.** The register records the project's own licence for each image, and says how the operating-system packages inside are covered (the image's parts list from the existing scan). **Say if that is not enough to state "open source" for the image as a whole.**
4. **The GOV.UK typeface (GDS Transport) is not this slice's to change:** its files leave the default build in the identity-switch slice after PL4's slice E (`slices/PL7c.md`). It is not a sovereignty gap; that ruling stands. The register lists it as conditional (see item 4 below).
5. **The stale table in the specification that still lists MinIO is corrected in this slice.**
6. **The gate's Makefile wiring comes to the owner as a diff.** Do not edit the Makefile (protected).
