## What DOC1a found (read, not measured)

- The licence gate (tools/licence_check.py, tools/licence_check.mjs) covers Python and Node package metadata, Dockerfile runtime labels, demo data licences and the project's own LICENSE and NOTICE. It does **not** see model weights, map data, fonts, base images or operating-system packages.
- **Weights in a default local-lite install:** three Ollama models (a 0.5B Qwen instruct, an all-minilm 22M embedding model, a moondream 1.8B vision model) pulled on each start; a Whisper tiny English speech model fetched on start; Stanza English models baked into the NER image; the extraction default (Qwen 7B or 14B) recorded as Apache-2.0. **No licence is stated in the repository for the first three, nor for the Whisper or Stanza weights**; Laurium's weights are not stated.
- **Map data:** OpenStreetMap-derived tier 1 (ODbL), tier 2 OS OpenData (OGL), tier 3 not redistributable; glyphs SIL OFL; Natural Earth not located.
- **Components not stated in the repository:** ArcadeDB and Ollama; LiteLLM "MIT core" with an enterprise folder possibly in the image. The specification's vault table still lists MinIO (AGPL-3.0); the install uses SeaweedFS (a stale table).
- **Gate shape gaps:** the Python allowlist has no spelling for OFL-1.1 or Python-2.0 although the specification allows both; Python is checked only in the build environment (per-image sets only for the NER and Laurium images).

## What (a first cut, for the scout and the owner to settle)

1. A register in the specification (one table, a row per model weight, map dataset, font file family and base image: name, source, version or digest, licence, whether it is open source by the OSI definition, where it is fetched or built) and a gate that reads the register and fails when a default install uses something the register does not list, or lists with a licence not on the allowlist; shown red on a planted unlisted weight and green on the real register (rule 15).
2. The weights whose licences are not stated: find each licence from the model's own card or licence file and record it; **where a weight is not open source, bring it to the owner as a question before it is registered** (never decide it silently).
3. The stale vault table corrected; the allowlist spellings added with tests.
4. Out of scope: GDS Transport (the owner, 20 November: it applies only to UK government, which is sovereign over it; its handling stays with PL7 and AD4).
