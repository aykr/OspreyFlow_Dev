Reproducible: `plants_L3.7.py` in this folder (`--live` for the store plants, under a lease). Each plant is an
exact-string replacement asserted to occur once, at the call site the test reaches, and put back after its run.
The runner runs every named test unplanted first and stops unless all pass; a plant counts as red only when
pytest reports failed tests and no error (a collection, import or fixture error proves nothing); and each run
has a bytecode cache of its own. That last was found the hard way: two plants of `answers.py` left it the same
size within one second, Python ran the first plant's cached bytecode for the second, and the second was
reported red without being exercised. Under the fixed runner it is red by hand and by the runner.
Run again at the gated commit after the rebase onto L1.6, the plants found the rebase's own defect: the
conflict's resolution had kept round 1's  line beside round 2's, which for a scheme file
named its path (605cc87; the plant "a second scheme line rendered").

Paths that are not the one a title might suggest (rule 15's second paragraph):
- With the deployment-scheme guard removed, the mapping-from-another-scheme test first stayed green, because
  its items were in 5x5x5 and another check refused the same input for its own reason. Its item is now drawn
  in the mapping's own old scheme, and it asserts the guard's words.
- Removing the withdrawn filter does not regrade a withdrawn item: the store (and the fake) gives back no
  withdrawn (reverted) element, so it counts as unread and the change is refused whole. The row is titled for
  that. The registry's own SQL filter is a live row.
- Round 2 first planted "the command's adapter given no ontology" and "not composed with the proposals"; both
  stayed green. Writing the grade alone (`regrade_drawn`) left the command needing no ontology, and its reads
  find a proposed type's links under their stored label's name. The ontology step was dead code, so it was
  removed, and the live test now runs `_main` with no aliases set, as a one-shot starts.
- "A second change overwrites the original" first stayed green live, because the live test made one change.
  It now makes the change back.
