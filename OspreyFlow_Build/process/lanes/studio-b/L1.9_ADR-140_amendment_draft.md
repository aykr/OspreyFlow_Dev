# Draft: ADR-140, Amendment <n> — L1.9 part 1 as built: the S3 and Athena connectors

*For the number the orchestrator reserves (the build plan's row L1.9: "ADR-140 amendment (to reserve)"). Not in
`06_DECISIONS.md` until reserved: an ADR is edited only by a new amendment under a reserved number. 09 §2's "Amazon
S3 and Amazon Athena" carries the as-built prose meanwhile.*

Status: built by studio-b at L1.9 part 1 on the test server, 11 November 2026, under Prompt L. An access step
(ADR-142 Amendment 8 decision 7): two review rounds. The decisions the brief left open were taken as recommended
and are listed in `process/lanes/studio-b/SERVER_LOG.md` for the owner to overrule.

1. **Two connection kinds, `s3` and `athena`**, named in *Admin › Connections* and bound to datasets as
   Amendment 13's are; each read lands as the source's one file, so everything after is unchanged.
2. **No credential, anywhere.** Neither kind's settings can hold a key or a secret's name; each read signs in as
   the deployment's own cloud identity (ADR-148: the namespace's IAM role, wired in part 2). A test stands its
   stand-in's credentials in through `connector_reads.Readers`, never through settings.
3. **No typed host.** The host is made from the region (and bucket) and checked against the egress allow-list
   before any read or test (ADR-148 decision 7). Dotted bucket names are refused.
4. **S3 reads a folder under the connection's**, CSV or Parquet, every object in key order, hidden objects never;
   the bucket is asked for first. **Athena reads a table** (a statement built from two checked names) **or a named
   query** that is one SELECT, in the connection's workgroup and databases, checked before it is sent.
5. **Rule 2.** Sizes summed before any object is opened; 1,000 objects; Parquet rows from the footer; Athena's
   rows, bytes and pages counted as they come; each refused whole. A query past 300 seconds is stopped.
6. **Rule 15.** S3 against SeaweedFS (the build's own pinned image), whose first green was not a result (a missing
   bucket read as an empty folder, fixed); Athena against a recorded fixture behind botocore's real client that
   refuses what Athena refuses, its answers from AWS's API reference, confirmed only by the live test on the
   client's platform.
7. **Dependency:** `botocore` (Apache-2.0), already in `uv.lock` through cloudpathlib's extra.

**The test that would fail.** `tests/connectors/test_s3_connector.py`, `test_athena_connector.py`,
`test_s3_connector_live.py`, `tests/services/api/test_cloud_connector_access.py`; red records in
`process/lanes/studio-b/L1.9_RED_RECORD.md`.
