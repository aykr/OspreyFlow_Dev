| 2026-11-12 | defect (caught by testing the real dependency) | The shared key in the proxy (ADR-114 Amendment 41) was first designed as plain HTTP Basic. Running the real Caddy before writing the render showed two things a stand-in would not: the Glass's API sends its own `Authorization: Bearer`, which a browser sends in place of stored Basic credentials, so the whole Glass would have been refused; and the service behind received the key itself. The lane review then found, and the real Caddy confirmed, that Caddy's `path` matcher cleans a path before matching, so `.../auth%2F..%2Ftoken` matched an open answer and went on raw. | A session pass once the key is checked (host-only after the orchestrator's question on scope), every Basic credential taken off before the services, the open answers matched on the path as asked, not as cleaned. Before writing configuration for a proxy, run the proxy: its refusals and its matchers' semantics are the specification, not its documentation's summary. A path exemption is matched on the path the service will receive. | `platform-b/gate/B-*`, `spec/06_DECISIONS.md` ADR-114 Amendment 41. Hash: recorded at merge. |
